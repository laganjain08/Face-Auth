# Face Auth

Face Auth is a web-based facial authentication system that uses facial recognition for user registration and login.

## Features

- User registration using facial authentication
- Face-based login
- Dashboard for authenticated users
- Image and face verification
- Error handling for authentication failures

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- OpenCV
